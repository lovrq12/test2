# 🌑 NIGHTMARES — كوابيس

لعبة مافيا متعددة اللاعبين عبر الإنترنت بهوية dark fantasy مميزة.

---

## 🚀 النشر على Vercel + GitHub

1. ارفع المجلد كاملاً على GitHub (جديد أو موجود)
2. افتح [vercel.com](https://vercel.com) → New Project → استورد الـ repo
3. اضبط الـ Framework على **Other**
4. انقر Deploy — الموقع سيعمل مباشرة

---

## 🎮 كيف تلعب

1. **إنشاء غرفة**: أدخل اسمك، اختر رمزك، اضغط "إنشاء غرفة"
2. **مشاركة الكود**: أرسل كود الغرفة (5 أحرف) للاعبين الآخرين
3. **الانضمام**: اللاعبون يدخلون الكود في صفحة البداية
4. **المضيف**: يضبط الإعدادات والأدوار الخاصة ثم يضغط "ابدأ اللعبة"
5. **اللعب**: تتناوب مراحل الليل والنهار والتصويت

## 🃏 الأدوار

### الأساسية
| الدور | الفريق | القدرة |
|-------|--------|--------|
| مافيا | مافيا | قتل لاعب كل ليلة |
| طبيب | مواطنون | حماية لاعب كل ليلة |
| محقق | مواطنون | كشف هوية لاعب كل ليلة |
| مواطن | مواطنون | لا قدرة — التصويت فقط |

### الخاصة
| الدور | الفريق | القدرة |
|-------|--------|--------|
| الملعون | مافيا | خمّن دور لاعب — أصبت: يموت، أخطأت: أنت تموت |
| المواطن المحصن | مواطنون | ينجو من أول ضربة ليلية |
| الهمسة | مافيا | اكشف دور لاعب لنفسك فقط 10 ثوانٍ |
| المؤسس | مافيا | جمّد الأصوات وصوّت منفردًا |
| ضحية أم بطل؟ | محايد | فوز منفرد إن تم إعدامه بالتصويت |
| محطم الآمال | مواطنون | اكشف مافياً علناً فيموت فوراً وتنجو — إن أخطأت تموت وحدك |
| العنقاء | محايد | يرى دور كل ميت — يحيي لاعباً وينضم لفريقه |

## 🔧 تقنيات

- **HTML / CSS / JavaScript** فقط — لا frameworks
- **Firebase Realtime Database** للتعدد اللاعبين

- يعمل على **GitHub + Vercel** مباشرة
